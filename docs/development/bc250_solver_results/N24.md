## Recovery and failure contract

`right_eigenvectors(SchurResult)` requires a converged result (`info==0`), finite
matching complex64/128 GPU T,Q of order1..16, exactly upper triangular T and a
sufficiently unitary Q. Q is checked with Frobenius bound128×n×eps. Autograd
inputs, mismatched/nonfinite/nonunitary forms and unconverged results are refused.
T,Q and the original matrix are not modified.

For n>1, divide T by its largest entry magnitude and check the minimum pairwise
scaled diagonal gap against **8×sqrt(eps)** (about0.002762 for complex64 and
1.1921e-7 for complex128). Zero/subnormal overall scale or insufficient separation
is refused. This deliberately conservative policy rejects repeated/close spectra;
it is not an eigenvalue-conditioning estimate or a matrix condition guarantee.

For eigenvalue j, set y[j]=1, y[j+1:]=0 and solve the preceding upper-triangular
rows backward. Check each pivot against the same floor, never perturb it, and
rescale the homogeneous partial solution by its maximum magnitude at each row.
Nonfinite/zero solutions are errors. Normalized triangular eigenvectors must
satisfy the scaled columnwise backward residual bound64×n×eps before transformation.
Finally compute and normalize V=QY on the GPU. This produces right eigenvectors,
which generally are not orthogonal for a nonnormal matrix; Q alone is not V.

`EigenvectorResult` returns values in matching Schur order, unit-norm vector
columns, minimum relative separation and maximum triangular residual. A scalar
matrix, including zero, takes the trivial scalar path. No eigenvalue ordering or
phase is prescribed. There is no host LAPACK fallback on rejection. Candidate
matrix/vector arithmetic stays on the current GPU stream; Python loop/validation
reads scalar tests and synchronizes host control as in N2.3.

Example for the **staged experimental helper**, outside production Torch dispatch:

```python
import gfx1013_schur_candidate as candidate
schur = candidate.schur(gpu_complex_matrix)
# Raises on nonconvergence, unsupported separation or unstable recovery.
pairs = candidate.right_eigenvectors(schur)
w, v = pairs.values, pairs.vectors
```

This is not a drop-in public Torch eig API. The supplied Schur form is responsible
for representing the original matrix; recovery can validate T/Q structure and
numerics but cannot verify A=QTQᴴ without the original A. End-to-end tests do verify
original-matrix eigenpair residuals independently.

## Limits and next step

Separation refusal is qualified; arbitrary close/repeated/defective eigenvector
support is not. No balancing, general extreme-scale reliability, robust conditioning
estimate, left vectors, batching, autograd, compile/graphs, concurrency, large
matrices, speed or sustained stability claim. Scalar host synchronization remains
expensive; correctness here does not establish useful performance.

Next N2.5: qualify a bounded scale ladder and spectral-separation boundary for the
small eigenpair pipeline, including nonnormal cases and explicit refusal controls;
fix demonstrated scaling/residual defects before considering any opt-in Torch
integration. Keep the production host path unchanged during that investigation.
