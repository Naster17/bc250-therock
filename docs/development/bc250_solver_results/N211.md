## Measured cause and ownership

The initial six-fixture/three-sample profile attributes~3.13–3.18ms to handle
creation,~0.11–0.13ms to library binding,~0.06–0.08ms to owned packed/tau
allocations/copy and~0.13ms to handle destruction in representative warm samples.
GEHRD/device Q themselves remain short. The first before-profile device-Q sample
also includes cold standalone-library initialization; raw samples are retained.
This supported handle reuse, rather than caching caller matrices or outputs.
Native rocBLAS handle allocation/destruction and stream implementation were
inspected locally; no ROCm native source change was required.

The session owns CDLL references, typed function pointers, its native handle and
its stream object. Each operation still allocates an owned overwritten GEHRD
copy/tau and rebinds the handle to the checked current stream. Different streams
must use different sessions, preventing workspace aliasing from reusing an
in-flight handle across streams. Host-thread/PID guards run before GPU input
validation. Closed, wrong-device, wrong-stream, busy and invalid sessions are
refused, including scalar/zero shortcuts. A session is not reentrant or shareable
between host threads. `close()` is idempotent, synchronizes its pinned stream
before native destruction, clears the handle, and is called by the context manager
on success or exception. There is no GPU teardown in a Python finalizer; callers
must use a context manager or explicitly close the resource.

Example inside the qualified runtime, with GPU tensor `a`:

```python
import gfx1013_schur_candidate as candidate

with candidate.GehrdSession() as session:
    result = candidate.schur(
        a, qr_backend="device_control", q_backend="device", session=session
    )
    # Further calls on this same host thread/device/current GPU stream reuse it.
```

The helper remains cap16/complex64+128. Native GEHRD/Q/QR arithmetic, normalization,
iteration/deflation/fill/separation and eigenvector residual/refusal gates are
unchanged. No batching/gradients/balancing/graph/general convergence or unrestricted
concurrency contract is added. A bound session is an optional prototype resource,
not a new public Torch/rocSOLVER API.
