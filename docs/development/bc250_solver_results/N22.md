# N2.2 nonsymmetric complex eig — 2026-10-15

**Bounded host-LAPACK compatibility qualified; native GPU eig remains missing.**
The existing pinned `torch.linalg.eig`/`eigvals` GPU-tensor interface passed16
checks on .104. No backend defect was reproduced and no runtime code, dispatch
policy or defaults were changed. This is not native GPU nonsymmetric eig support.
N2.1's native Hermitian `eigh` result is a separate operation and remains valid.

   `/workspace/build/dist/rocm`, not staging libraries. CPU complex128 references

   and mathematical residuals are therefore also required, not just CPU equality.

Pinned rocSOLVER has Hessenberg reduction (`roclapack_gehrd*`) but the source
inventory found no geev/hseqr/lahqr/gees implementation. A native nonsymmetric
solver requires a reviewed Schur/QR iteration and convergence/vector recovery
contract; removing the host call is not a sufficient implementation. No generic
hardware impossibility is inferred from the current library gap.

## Bounded tests

`build_tools/bc250/validate_solver_n22.py` constructs known diagonalizable complex
matrices `X diag(lambda) X^-1`, with strictly separated real eigenvalue parts and
complex imaginary parts. Basis condition targets1 and20 give normal and nonnormal
fixtures; these are **basis** conditions, not matrix condition-number guarantees.
Inputs are rounded to complex64/complex128 before CPU complex128 reference solves.

- Twelve batch2 fixtures: both complex types, dimensions9/33/65, normal/nonnormal,
  padded or transposed strided GPU views. CPU and known analytic spectra are
  compared; matching sorts separated real parts without assuming API ordering.
- Eigenpair residuals, normalized right vectors and rank-one projector references
  avoid arbitrary vector phase comparisons. Both eig and eigvals paths execute
  for every fixture. Input and guard lanes remain unchanged.
- Every fixture uses a nondefault stream with explicit producer/consumer waits.
- Two separated-spectrum eigenvalue-loss backward checks compare GPU-interface
  gradients against CPU complex128. No eigenvector-gradient or repeated-spectrum
  derivative claim.
- Two grouped empty-input checks each cover (0,0), (0,3,3), (2,0,0). These test
  Torch's empty fast path and do not execute LAPACK.
