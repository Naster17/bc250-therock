## Evidence and implementation

The initial six-fixture, three-sample synchronized diagnostic separates GEHRD
from reflector-Q formation. At order16 GEHRD takes~0.37–0.40ms, Q~1.87–1.91ms,
within~6.2ms total preparation. Most remaining time belongs to setup/teardown,
validation and allocations; this step does not identify their individual costs.
Measurements include host work and explicit synchronization, not pure kernels.
The before-run source hash/results remain in solver-prep-n210-before.

One32-thread kernel forms Q from the native column-major GEHRD packed matrix
and complex tau, using the same ordered product of I-tau*v*v^H. Implicit vector
zeros/one and stored lower tails match the reference. Rows update independently
in padded shared storage; barriers protect each reflector's vector. Inputs are
read-only and outputs are owned. The Python reference loop remains available;
`phase_times` is explicit diagnostic instrumentation only. The native handle
lifetime, current-stream binding, owned GEHRD copy and triangular-H extraction
are unchanged. The private wrapper copies noncontiguous packed/tau inputs to the
required layout on GPU; it does not read matrix data on CPU.

Qualified scope remains one complex64/128 matrix, cap16. Public scalar/zero
behavior and all Schur normalization, QR budgets/control, deflation/fill,
separation and recovery residual/refusal contracts are preserved. No batching,
balancing, gradients, compile/graphs, concurrency or general convergence contract.
This standalone private kernel is not a new public rocSOLVER/Torch API.

- 128 unchanged retained N2.3–5 groups pass through device Q + N2.8 QR control:
  Schur21, eigenvectors21, scale40, separation30 and failure16. N2.3 direct
  Hessenberg calls also explicitly select device Q.
- 24 independent CPU complex128 reflector-product cases: both dtypes,
  orders2/4/9/16, complex unitary tau, all-zero tau and mixed zero/nonzero tau.
  Reference uses quantized packed/tau values and full explicit matrix products,
  independent of the GPU row-update implementation. Fixed comparison32*n*eps,
  unitarity128*n*eps, padded/strided input guards and nondefault streams pass.
- Six complete eigenpair fixtures test both Q backends with reference, N2.8
  device_control and N2.9 device_chunked QR. CPU eigenvalues/residual/projector
  gates retain8e-6/4e-12 residual and8e-4/6e-10 comparison bounds. No tolerance
  or iteration-limit changes. The default reference exactly matches immutable
  N2.9 output/counters; H is bitwise equal across Q backends on those fixtures.
- Zero/scalar Hessenberg controls, two unknown-Q-backend refusals and input
  immutability pass. A Kineto trace shows actual `small_gehrd_form_q` GPU kernels.

All seven GPU processes, including the initial profile and five regression
groups, exit0 with acknowledged600s guards and byte-identical dmesg. No failed
GPU run in this batch. This evidence does not qualify arbitrary dynamic ranges
or unsupported/nonfinite private packed/tau inputs.
